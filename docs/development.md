# 소스 실행과 테스트

Python 3.10 이상이 필요합니다. 아래 명령은 저장소 최상위 폴더(`pyproject.toml`이 있는 위치)에서 실행합니다.

## 소스로 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m cleanfolder
```

화면 없이 미리보기만 확인할 수도 있습니다.

```bash
python -m cleanfolder --preview ~/Downloads
```

GUI는 PySide6를 사용합니다. 공통 Core는 PySide6·AI·MCP SDK에 의존하지 않습니다. MCP를 사용하려면 [MCP 안내](mcp.md)에 따라 선택 의존성을 설치하세요.

## 테스트

```bash
python -m pip install -e '.[mcp]'
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
```

Core 안전 정책·설정·한글 문서 분류, MCP 경로 제한·승인·만료·stdio 통신, GUI 정리·파일 선택·휴지통·복구와 GUI↔MCP 상호 복구를 검사합니다. 1.6.0에서는 간편/상세 전환, 이전 설정 호환, 재시작 시 미리보기만 실행, 반복 폴더 재사용, 즉시 복구의 작업 ID 검증을 추가합니다. MCP SDK가 없으면 stdio 통합 테스트는 건너뜁니다.

## 1.6.0 설정 호환

새 설치의 기본값은 `view_mode="simple"`, `folder_mode="managed"`, `startup_mode="last"`입니다. 마지막 폴더가 없으면 폴더 선택부터 시작하며, 있어도 미리보기만 자동으로 표시합니다.

이전 JSON 설정은 `view_mode="detailed"`로 읽고 기존 명시된 시작 방식·분류 폴더 사용 방식은 유지합니다. 누락된 이전 기본값은 `new`·`empty`로 보완합니다. 설정을 읽는 것만으로 기존 파일을 다시 쓰지 않습니다. 저장 시 표시 방식은 JSON 최상위 `view_mode`에 기록하고, `settings` 안의 필드는 1.5.0과 동일하게 유지합니다. 1.5.0에서 다시 저장하면 새 표시 설정이 사라질 수 있지만 기존 분류·시작 설정은 읽을 수 있는 형태입니다.

간편/상세 전환은 표시 상태만 저장하고 분류 키에 영향을 주지 않습니다. 앱 생성 폴더 재사용·분류 규칙 변경은 다음 미리보기에 반영합니다. 임시 체크 해제는 세션 내 선택이며 영구 제외 규칙과 다릅니다.

## 파일 처리 기준

- 선택한 폴더 바로 아래의 일반 파일만 처리합니다. 기존 폴더·앱 번들·숨김 파일·심볼릭 링크는 제외합니다.
- 새 설치의 GUI는 기록으로 확인된 앱 생성 폴더만 재사용합니다. 기존 사용자의 새 폴더 생성 설정은 그대로 유지합니다. MCP 정리는 항상 새 폴더를 만듭니다.
- 기존 파일을 덮어쓰지 않습니다. 복구는 기록된 파일만 대상으로 하며, 해당 작업이 만든 빈 폴더만 제거합니다.
- 미리보기 이후 파일·대상 폴더·분류 설정이 바뀌면 다시 미리보기 해야 합니다. 이후 추가된 파일은 다음 정리 대상입니다.
- 하드 링크를 지원하는 로컬 파일시스템이 필요합니다. 미지원 볼륨에서는 이동하지 않고 오류를 알립니다.
- 미리보기의 체크 해제는 현재 폴더에서 유지되며 앱 재실행·폴더 변경 시 초기화됩니다. 계속 제외할 파일은 설정에 제외 규칙으로 저장하세요.
- 휴지통 이동은 GUI에서만 제공합니다. 휴지통으로 보낸 파일은 운영체제 휴지통에서 복원하며 정리 복구 대상에서는 제외합니다.
