# CleanFolder v1.5.0 — MCP 지원과 한글 문서 분류

## 배포 개요

미리보기 후 선택한 파일을 정리하고, 기록을 통해 파일 위치를 복구하는 데스크톱 앱입니다. 이번 버전에서는 GUI와 동일한 Core를 호출하는 MCP 인터페이스와 한글 문서 기본 분류를 추가했습니다.

일반 Mac 사용자, 한글·Office·PDF 자료를 다루는 학생·문서 작업자, MCP 클라이언트에서 로컬 정리를 호출하려는 사용자를 대상으로 합니다.

## 주요 변경

- MCP 도구 네 개: `scan_folder`, `preview_organization`, `organize_files`, `undo_last_operation`
- 허용 경로, 승인 후 실행, 5분 유효한 일회성 미리보기 ID, 복구할 최신 작업 ID 검증
- GUI와 MCP의 공통 작업 기록·잠금·복구
- `.hwp`·`.hwpx`를 기본 `Hangul` 폴더로 분류
- 이전 설정에 새 분류를 보완하며 사용자 지정 폴더 이름·확장자 분류·제외 규칙 유지

## 다운로드와 설치

[v1.5.0 다운로드](https://github.com/onechamp965/CleanFolder/releases/tag/v1.5.0)

| 파일 | 용도 |
| --- | --- |
| `CleanFolder-1.5.0-macOS-AppleSilicon.dmg` | 기본 설치 파일 |
| `CleanFolder-1.5.0-macOS-AppleSilicon.zip` | 실행 앱을 포함한 대체 다운로드 |
| `SHA256SUMS.txt` | DMG·앱 ZIP의 SHA-256 확인 |
| GitHub의 `Source code` 압축 파일 | 개발용 소스 |

Apple Silicon·macOS 14 이상용입니다. DMG와 앱 ZIP 중 하나만 받으면 됩니다. DMG에서 `CleanFolder.app`을 `Applications`로 옮겨 실행하며, 데스크톱 앱에는 Python과 실행 라이브러리가 포함됩니다.

Apple 개발자 인증서 서명·공증은 완료하지 않았습니다. 다운로드한 앱은 macOS에서 실행이 차단될 수 있습니다. Windows와 Intel Mac 설치본의 실사용 검증은 별도로 필요합니다.

## 사용 흐름

1. 정리할 폴더를 선택합니다.
2. 이동 위치를 확인하고 원래 위치에 남겨둘 파일의 체크를 해제합니다.
3. 선택한 파일을 정리합니다.
4. 필요하면 작업 기록의 **원래대로 돌리기**로 최근 미복구 작업을 복구합니다.

선택한 폴더의 최상위 일반 파일만 처리합니다. 기존 폴더 내부는 자동 재분류하지 않으므로, 이전에 `Others`로 정리된 한글 파일도 자동으로 이동하지 않습니다. 기록이 남아 있다면 해당 작업부터 복구한 뒤 다시 미리보기 할 수 있습니다.

복구는 파일 위치를 되돌리는 기능이며 파일 내용의 버전 백업은 아닙니다. 설치 파일의 휴지통 이동은 GUI 전용이고, 휴지통으로 보낸 파일은 운영체제 휴지통에서 복원합니다.

## MCP 실행

MCP 서버는 소스로 별도 실행하며 앱 설치만으로 클라이언트에 자동 연결되지 않습니다. [설치·설정·Inspector 안내](../mcp.md)를 참고하세요. 실제 사용자 승인 UI는 MCP 클라이언트에서 제공합니다.

## 검증 범위

2026-10-20 로컬 macOS, Python 3.13.11, PySide6 6.12.0, MCP SDK 1.30.0 환경에서 자동 테스트 116개를 통과했습니다. GUI는 offscreen 방식으로 검사하며 파일 처리·이전 설정 호환·MCP 경로와 승인 검증·실제 stdio 통신·GUI↔MCP 복구를 포함합니다.

이 결과가 Windows·Intel Mac·모든 파일시스템·다른 사용자 환경의 동작을 보장하는 것은 아닙니다. 하드 링크를 지원하는 로컬 파일시스템이 필요합니다. GitHub Actions 자동 테스트와 자동 릴리즈는 아직 구성하지 않았습니다.
