# CleanFolder v1.4.0 — 정리하지 않을 파일 선택

미리보기에서 정리하지 않을 파일을 직접 고를 수 있습니다.

## 사용 방법

1. 폴더를 선택합니다. 처음에는 정리 대상 파일이 모두 체크되어 있습니다.
2. 원래 위치에 남겨둘 파일의 체크를 해제합니다. 해당 파일에는 ‘원래 위치에 유지’가 표시됩니다.
3. ‘선택한 N개 정리’를 누르면 체크한 파일만 이동합니다.

- 모두 선택·모두 제외 버튼을 제공합니다.
- 선택한 파일 수·용량과 제외한 항목 수를 표시합니다.
- 전부 제외하면 정리 버튼을 비활성화하며 폴더·작업 기록을 생성하지 않습니다.
- 제외한 파일은 이동·복구 기록에 포함되지 않습니다.
- 같은 폴더에서 다시 미리보기·정리·복구해도 파일 이름 기준 제외를 유지합니다.
- 폴더를 바꾸거나 앱을 다시 실행하면 선택은 초기화됩니다. 계속 제외하려면 설정의 제외 규칙을 사용하세요.
- 체크 해제는 정리 이동에만 적용되며 설치 파일 탭에서 사용자가 별도로 선택하는 휴지통 이동과는 구분됩니다.
- 자동 테스트 90개를 통과했습니다.

## 다운로드와 지원 범위

- `CleanFolder-1.4.0-macOS-AppleSilicon.dmg`: 기본 설치 파일
- `CleanFolder-1.4.0-macOS-AppleSilicon.zip`: 실행 앱 ZIP, 개발용 소스가 아닙니다.
- DMG와 앱 ZIP은 둘 중 하나만 받으면 됩니다.
- Apple Silicon·macOS 14 이상용입니다. Apple 개발자 인증서 서명·공증 전이므로 실행이 차단될 수 있습니다.
- Windows는 빌드 구성을 포함하지만 실기기 빌드·실행 검증은 아직 필요합니다.
