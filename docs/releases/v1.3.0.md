# CleanFolder v1.3.0 — 설정 기능과 경량화

선택한 폴더의 최상위 파일을 종류별로 정리하는 macOS 앱입니다. 기존 공개 버전 v1.1.1 이후의 설정 기능과 경량화 변경을 함께 포함합니다.

## 주요 업데이트

- 분류 폴더 재사용 설정: CleanFolder가 만든 폴더만 재사용하며 사용자 기존 폴더는 보호합니다.
- 분류 확장자·폴더 이름 변경, 제외할 확장자·파일 이름 패턴 설정을 추가했습니다.
- 지정한 폴더 또는 최근 폴더로 시작할 수 있습니다. 자동 정리하지 않고 미리보기만 표시합니다.
- 시스템·밝게·어둡게 화면 모드를 선택할 수 있습니다.
- 핵심 정리 기능·화면·운영체제 연동·배포 설정을 분리했습니다.
- 불필요한 라이브러리 구성을 제외해 설치용 DMG를 약 39.2MiB에서 27.9MiB로 줄였습니다.
- 파일 분류, 덮어쓰기 방지, 선택한 설치 파일의 휴지통 이동, 작업 기록, 원래대로 돌리기는 유지합니다.
- 자동 테스트 80개 통과 및 macOS 배포본의 미리보기·화면 초기화·DMG 구성 검증을 완료했습니다.

## 다운로드

| 파일 | 용도 | 크기 |
| --- | --- | ---: |
| `CleanFolder-1.3.0-macOS-AppleSilicon.dmg` | 권장: 설치 화면에서 앱을 Applications로 드래그 | 약 27.9MiB |
| `CleanFolder-1.3.0-macOS-AppleSilicon.zip` | 대체: 압축을 풀고 앱을 Applications로 이동 | 약 25.4MiB |
| `SHA256SUMS.txt` | 위 배포 파일의 체크섬 확인 | — |

DMG와 앱 ZIP은 둘 중 하나만 다운로드하면 됩니다. GitHub가 자동 제공하는 `Source code (zip)`은 실행 앱이 아닌 개발용 소스입니다. 설치 후 앱 용량은 약 72MiB입니다.

## 지원 범위와 주의사항

- Apple Silicon Mac, macOS 14 이상용입니다. Intel Mac·Windows에서는 이 배포 파일을 사용하지 마세요.
- Python을 별도로 설치할 필요가 없습니다.
- Apple 개발자 인증서 서명·공증 전 빌드이므로 macOS에서 실행이 차단될 수 있습니다.
- Windows 빌드 설정은 소스에 포함되어 있으나 실제 Windows 빌드·실행 검증은 아직 필요합니다.
- 기존 작업 기록과 설정의 형식·저장 위치는 유지합니다. 업데이트할 때 기록 폴더를 삭제하지 마세요.
- 다른 컴퓨터에서의 설치·실사용 검증은 추가로 필요합니다.

전체 버전별 변경 내역은 저장소의 `CHANGELOG.md`를 참고하세요.
